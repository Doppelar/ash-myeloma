# ASH 多発性骨髄腫 演題ガイド

公開抄録に基づく日本語の演題ガイドです。治療薬、対象患者、発表形式で絞り込み、各演題の詳細と出典を確認できます。

## 開発と公開

- `npm ci` で依存関係を導入し、`npm test` を実行します。
- VercelでこのGitHubリポジトリを接続します。フロントエンドは `public/`、年度一覧を配信するサーバーAPIは `api/catalogs.mjs` です。
- NeonをVercelプロジェクトに接続し、サーバー側の `DATABASE_URL` を設定します。接続文字列はGitHubに登録しません。
- 公開できる演題データを用意し、`npm run db:publish -- data/2026.json` を実行すると、同じ開催年を更新します。翌年分も同じ形式で登録できます。
- Neonから取得できない場合は、同梱の2026年データを表示します。ブラウザーに読み込んだ年度JSONはそのブラウザー内で優先されます。
